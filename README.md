# Potato Game / El juego de la papa

A simple web game inspired by the classic pencil-and-paper game, designed for mobile browsers.

## Features
- Multilingual: Spanish & English
- Pencil & paper style UI
- Configurable players and number range
- Mobile-first, vertical only

## Folder structure

- src/assets: images, icons, fonts
- src/i18n: translations
- src/styles: CSS
- src/js: JS
- public: static files

## How to run
Just open index.html in your browser.
